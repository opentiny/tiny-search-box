# 更新日志

本页面记录 TinySearchBox 各大版本之间的功能更新与问题修复。

## v3.30

### Features

- 新增 input 类型支持，优化显隐逻辑 (#56)
- 时间支持 pickerOptions 配置，优化交互体验以及校验 (#61)
- `items` 数据项新增 `disableDelete` 配置，支持单个选项生成的标签禁止删除（编辑时仅可修改值，不可切换属性/类型） (#63)

### Bug Fixes

- 空数组 options 时 loading 一直显示，新增 asyncLoading 标志区分异步加载场景 (#58)
- 修复编辑模式切换属性时 replace 未生效导致同字段重复 tag (#59)
- 修复表单校验异常校验显示超出 (#55)
- 补充校验示例 demo (#54)
- 修复搜索选项显示条件等多个问题 (#53)

## v3.29

### Features

- 选项支持虚拟滚动 (#52)
- 校验支持抛出异常事件 (#50)
- 适配演练场，优化本地开发环境 SaaS 模式以及 CSS 导入逻辑 (#49)
- 更新依赖版本 (#45)

### Bug Fixes

- 修复滚动条背景色 (#48)
- 修复 SaaS 模式样式 (#47)
- 修复 docs 部署 (#46)
- 修复前缀图标偏上问题 (#43)
- 补充 vue2 环境 demo (#42)

## v3.28

### Features

- 新增图标后缀插槽，前缀图标支持隐藏 (#41)
- 支持二级面板回车事件 (#40)
- 弹窗支持挂载到当前 DOM 下 (#39)

### Bug Fixes

- 修复 docs 部署
- 修复 docDemo (#35)

## v3.27

首个 3.x 大版本，完成架构升级并完善工程化能力。

### Features

- searchBox 修改为 renderless 架构并支持构建发包流程 (#26)
- 支持 Vue2，完善 Vue2 文档 (#24)
- 搭建 Vue2 / Vue3 测试环境 (#27、#28)
- 添加构建任务 (#30)
- 支持转换为 Aurora，优化调整打包逻辑 (#33)
- 编辑时校验异常提交按钮禁用 (#34)

### Bug Fixes

- 修复快速输入后回车，一级面板偶现弹出，以及时间类型选中后属性丢失 (#31)
- 修复自动发包 (#32)
- 修复 docs 部署 (#29)

## v0.1

项目初版，完成基础搜索能力与发布流程。

### Features

- 支持 size 尺寸配置 (#18)
- API 文档补全 (#6)
- 删除 vue-i18n 依赖，新增 release 脚本，优化构建流程 (#2)
- 支持打包发布
- 支持 e2e 与功能文档优化 (#51)

### Bug Fixes

- 修改默认导出入口文件类型 (#19)
- 添加缺失的 initUse 翻译键 (#15)
- 修复国际化问题 (#13)
- 修复潜在匹配项选中后 id 丢失无法修改问题 (#11)
- 修复 SSR 构建失败 (#10)
